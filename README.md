# FreshCoin (FRESH)

Official token plan and documentation for **FreshCoin (FRESH)** — the utility token for [FreshMinds](https://freshminds.nl), a Dutch IT consultancy, built on the **Cardano blockchain**.

## Key Use Cases

1. **Client Loyalty Rewards** — Earn FRESH on contracts, referrals, early payments
2. **Employee Incentives** — Bonuses, peer recognition, tenure rewards
3. **Partner Referral Network** — Reward ecosystem partners for bringing in business
4. **Governance** — Token-weighted voting on company initiatives
5. **On-Chain Credentials** — Verifiable certifications and project badges
6. **Knowledge Sharing** — Reward internal content and open source contributions
